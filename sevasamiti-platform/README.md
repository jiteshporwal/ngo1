# SevaSamiti Platform

This repository contains the full-stack SevaSamiti Platform, consisting of a React-based frontend and a Spring Boot (Java) backend.

## Getting Started

To set up and run the entire project, please follow the instructions below for both the frontend and the backend.

### 1. Frontend Setup

The frontend application is located in the `frontend/` directory.

To install dependencies and run the frontend, please refer to the dedicated README:
[Frontend README](frontend/README.md)

### 2. Backend Setup

The backend application is located in the root of this directory (`sevasamiti-platform/`).

To install dependencies and run the backend, please refer to the dedicated README:
[Backend README](backend/README.md)

---

Please ensure you have Node.js (with npm) and Java (with Maven) installed on your system to run both parts of the application successfully.
