# Frontend Setup

This directory contains the frontend application for the SevaSamiti Platform.

## Dependencies

The project uses Node.js and npm for dependency management. The dependencies are listed in `package.json`.

## Installation

To install the frontend dependencies, navigate to this directory and run:

```bash
npm install
```

This command will read the `package.json` file and install all required packages.

## Running the Application

To start the development server, run:

```bash
npm start
```

This will open the application in your browser, usually at `http://localhost:3000`.

## Building for Production

To create a production-ready build of the application, run:

```bash
npm run build
```

This will compile the application into the `build` directory.
